# Week 2 Assessment - Docker + Jenkins CI/CD

## 📌 Objective
Build and deploy a full MERN stack application using Docker Compose and automate Docker image builds using Jenkins CI/CD pipeline.

---

## 🧱 Project Structure
- Backend (Node.js + Express)
- Frontend (React + Vite)
- MongoDB (Docker Container)
- Docker Compose for orchestration

---

## ⚙️ Tech Stack
- Docker
- Docker Compose
- Jenkins
- Node.js
- React
- MongoDB
- Docker Hub

---

## 🚀 Workflow

1. Application runs using Docker Compose
2. Services communicate via internal Docker network
3. Jenkins builds Docker images automatically
4. Images are pushed to Docker Hub

---

## 🐳 Docker Compose Services

- frontend
- backend
- mongodb

---

## 🔥 Jenkins Pipeline Stages

- Checkout Code
- Build Backend Image
- Build Frontend Image
- Docker Login
- Push Images to Docker Hub

---

## 📦 Deliverables

- docker-compose.yml
- Dockerfiles (frontend + backend)
- Jenkinsfile
- Docker Hub image links
- Running application screenshots

---

## 🎯 Outcome

Successfully implemented full CI/CD pipeline for MERN stack using Docker + Jenkins.
